Weird-Factory is a 3D top-down factory automation game (Unity 2022.3, C#).
User is building this project themselves, learning game architecture.
Read PROJECT_STATUS.md at conversation start for full context: current progress, script inventory, architecture decisions, and user preferences.

Key principles: data-driven (logic before rendering), Satisfactory-style shared input buffers, no ItemStack struct (deleted), user writes code / AI explains and reviews.
